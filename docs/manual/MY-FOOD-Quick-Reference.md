# MY FOOD — Quick Reference

**www.chefelisha.cc** · Keep this card at every till. Never write a PIN on it.

| Task | Steps |
|---|---|
| **Sign in** | Till shows **Enter your staff PIN** → type your PIN → **Sign in**. Leaving the till: **Lock**. |
| **Open register** (cashier) | **Open register** → count the float → **Opening cash (GHS)** → **Open register with GHS …** |
| **Table order** | Area tab (e.g. **Dining**) → tap the table → tap products → **Send to kitchen** |
| **Takeaway order** | **Takeaway** → **+ New takeaway order** → **Customer name** (+ phone) → products → **Send to kitchen** |
| **Add more items** | Open the order → tap products → **Send to kitchen** (only the new items go) |
| **Bill** | **Print bill** → prints **BILL - NOT PAID**. A bill is **not** a receipt. |
| **Cash** | **Take payment** → **CASH** → **Cash received** → check **Change** → **Complete payment** |
| **MoMo** | Wait until the customer's phone shows success → **MOMO** → transaction ID → **Complete payment** |
| **Card** | Wait until the card machine approves → **CARD** → slip reference → **Complete payment** |
| **Split** | **SPLIT** → method + **Amount for this payment** → **Record this payment** → repeat |
| **Receipt** | **Print receipt** |
| **Food handed over** | **Served** (table) or **Picked up** (takeaway) |
| **Kitchen screen** | **ACCEPT** (we have it) → **START** (cooking) → **READY** → **DONE**. **RECALL** brings a ticket back. **VOIDED · STOP PREPARATION** = do not make it. |
| **Close register** | **Close register** → **Count the cash** → **Actual cash counted** → **Review** → **Close register** → **Export** → **PDF** |
| **No internet** (online mode) | Keep the order open; press **Retry send** when it's back. Nothing is sent twice. |
| **Restart a device** | Just restart. It stays paired. |
| **Printer not printing** | Paper? Power? Cable? → printing PC on, and **MY FOOD Printing** says **Printing is on**? → tell a manager |
| **Wrong PIN 5 times** | Wait 10 minutes, or ask a manager to **Reset PIN** |

## Pairing a device (managers)

1. On the device: open **www.chefelisha.cc/pair**. It shows a code like **K7M4-Q2RT**.
2. On your phone: **Devices & printing** → **that device's row** → **Enter code from device** → type the code → **Pair device**.
3. The device continues by itself.

> **STOP before making new codes.** If the code is still on the screen, it still works.
>
> - A code **from a device** goes on **that device's row** (**Enter code from device**).
> - A code from **Create code** is typed **on the device** (**I have a code from a manager**).
> - **MY FOOD Printing** codes go only on **PRINT-AGENT-01**. **Hub** codes go only on the **Hub** row.
